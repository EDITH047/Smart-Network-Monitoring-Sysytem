Component Interaction Map

How each module communicates at runtime:

User Login

  • LoginFrame → AuthService
  • AuthService → UserDAO
  • AuthService → AuditLogDAO
  • On success → MainDashboard

Network Monitoring

  • Timer → MonitoringService
  • MonitoringService → DeviceDAO (get devices)
  • MonitoringService → MetricDAO (save metrics)
  • MonitoringService → AlertService (check thresholds)
  • MonitoringService → SecurityService (analyze)

Security Detection

  • SecurityService ← MonitoringService (trigger)
  • SecurityService → SecurityEventDAO
  • SecurityService → BlockedIPDAO (auto-block)
  • SecurityService → AlertService (CRITICAL)

Firewall Management

  • FirewallPanel → FirewallService
  • FirewallService → FirewallRuleDAO
  • FirewallService → AuditLogDAO (log changes)
  • SecurityService → FirewallService (auto-rules)

Optimization Engine

  • OptimizationPanel → OptimizationService
  • OptimizationService → MetricDAO (query 24h data)
  • OptimizationService → OptimizationDAO (save results)
  • Calculates score, generates recommendations

Alert System

  • AlertService ← MonitoringService (trigger)
  • AlertService ← SecurityService (trigger)
  • AlertService → AlertDAO (save alerts)
  • AlertService → MainDashboard (badge update)

Runtime Data Flow — Full Cycle

What happens every 10 seconds when the monitoring timer fires:

// Complete runtime cycle (every 10 seconds) Timer fires │ ├─▶ MonitoringService.collectMetrics() │ │ │ ├─▶ DeviceDAO.getAllDevices() // Get device list │ │ │ ├─▶ For each device: │ │ ├─▶ InetAddress.isReachable() // Ping check │ │ ├─▶ simulateTraffic() // Generate metrics │ │ ├─▶ MetricDAO.insertMetric() // Save to DB │ │ ├─▶ DeviceDAO.updateStatus() // Update ONLINE/OFFLINE │ │ │ │ │ ├─▶ AlertService.checkThresholds(metric) │ │ │ ├─▶ bandwidth > 90%? → AlertDAO.insertAlert(CRITICAL) │ │ │ ├─▶ latency > 200ms? → AlertDAO.insertAlert(WARNING) │ │ │ └─▶ packet_loss > 5%? → AlertDAO.insertAlert(WARNING) │ │ │ │ │ └─▶ SecurityService.analyze(metric) │ │ ├─▶ packets_in > 100K? → DDoS event │ │ ├─▶ Repeated failures? → Brute force event │ │ ├─▶ Unusual ports? → Port scan event │ │ │ │ │ └─▶ If CRITICAL: │ │ ├─▶ SecurityEventDAO.insertEvent() │ │ ├─▶ BlockedIPDAO.blockIP() │ │ └─▶ AlertDAO.insertAlert(CRITICAL) │ │ │ └─▶ Return updated metrics list │ └─▶ MonitoringPanel.refreshTable() // Update JTable on EDT ├─▶ Update summary cards ├─▶ Redraw chart └─▶ MainDashboard.updateAlertBadge() // Update alert count

Demo Script for Project Presentation

Follow this sequence to showcase all features in 10–15 minutes:

Step 1: Login

Log in as admin. Show dashboard. Point out tabs and user info.

Step 2: Add devices

Add 2–3 devices (use local IPs like 192.168.1.1). Show CRUD operations.

Step 3: Monitor

Switch to monitoring tab. Wait for auto-refresh. Show live metrics updating.

Step 4: Security event

Trigger a simulated threat (the system should auto-detect one from metrics). Show it in security tab.

Step 5: Alert

Show alert badge on dashboard. Open alerts tab. Acknowledge an alert.

Step 6: Firewall

Add a firewall rule. Toggle it on/off. Show the blocked IPs list.

Step 7: Optimization

Run optimization analysis. Show scores and recommendations.

Step 8: Report

Generate a report. Export to CSV. Open the CSV file.

Step 9: RBAC

Logout. Login as VIEWER. Show restricted access (can't add/delete).
